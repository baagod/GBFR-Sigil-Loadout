Size = 盒子的三围

判定盒是一个看不见的长方体。Size 的三个数就是它三条边的长度： x、y、z；第 4 个数永远写 0。

地上的 ● = 人物位置（技能原点），判定盒从这里发出。

三条边（米）

x 边0.70
y 边4.00
z 边2.50

偏移（Offset，米）

盒子 x 偏移0.00
盒子 y 偏移（高度）0.00
盒子 z 偏移（前方）0.00

Offset = 判定盒中心相对人物（红点）的位置；它只移动盒子，不改变尺寸。默认 0 就是盒子罩住人物；游戏数据是 (0, 0.7, 3.5)。

盒子姿态（Rot）

绕 x 转0°
绕 y 转0°
绕 z 转0°

旋转方向：正角 = 逆时针（从 +z 一侧看），负角 = 顺时针。

高亮
