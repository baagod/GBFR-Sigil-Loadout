# 角色动作表：选择 / 复制区的边框**最小案例（本仓库实现）**

> **这是什么**：把「角色动作」页的**选区实线 + 复制区虚线**抽出来的**最小可运行复现** ——
> 一个 HTML 文件、一张表、一段 30 行的脚本。本文里的 HTML 已在 WebView 里跑过：
> 角格 `[3,0,0,3]`、"四条边全亮"的格子 = 0、虚线 `z-index: 2` 且压在实线之上。
>
> **规格以代码为准**：`SigilLoadout/frontend/src/style.css` 里那几段注释是唯一真相来源
> （提层阶梯 / 复制区四条不变量 / 垫底层 / 选区几何）。本文只做**最小复现 + 为什么**。
>
> **起源**：初版参考的是一个 3×3 白底案例（`border-spacing` 网格 + `outline` 实线 + 整格 `z-index: 10`）。
> 落到本表时改了四处，**照抄原案例会踩坑** —— 见文末「与原案例的差异」。

---

## 一、几何：两条线各占哪几像素

基准 `p` = 格子内边界（padding box 的边）；**格线是格子自己的 `border-right / border-bottom`（1px）**：

| 线 | 跨距 | 实现 | 含义 |
| --- | --- | --- | --- |
| **实线**（选区） | `[p-1, p+2)` = 3px | `inset: -2px` + `border-width: 3px` | 格外 1px + 与格线重合 1px + 格内 1px |
| **虚线**（复制区） | `[p-1, p+1)` = 2px | `inset: -1px` + `border-width: 2px` | 与格线重合 1px + 格内 1px = **实线靠内那 2px** |

两条线都画在**伪元素**上（实线 `::before`、虚线 `::after`），绝不写 `td` 自身的 `border`：
那会改布局、也画不到"格外"那 1px。`inset` 的量 = **线宽 − 1**（`3px → -2px`、`2px → -1px`），
这条关系由 `--edge-w` 一处定义、`--copy-w` 从它派生。

## 二、四条不变量（每条都对应一次真实故障）

1. **格内顺序定胜负，整格不提层。**
   `::before`（实线，`z-index: 1`）< `::after`（虚线，`z-index: 2`）—— 虚线压住实线只靠这一条。
   ‼️ **复制区格子不许提整格 `z-index`**：一提，它的不透明底色 + 垫底带就压过**邻格**的选区边框，
   把人家 3px 咬掉 2px（真机同坐标 1:1 差分实测：相邻场景丢 96 个绿像素；不提层为 0，
   而"虚线压住实线"的效果**逐像素不变**）。
2. **一个类管一条边（变量），别合并成一条规则。**
   角上的格子同时挂两个类，变量各管一条、互不覆盖；
   写成 `:is(.cell-edge-top, …)::before { border-width: … }` 会给**四条边一起**上色 ——
   内部格挂一个类就长出一整圈实线（破"选区内部无线"）。
3. **虚线缝要垫底，且垫的是"该格自己的底色"。**
   虚线的线段之间是透明的，底下压着实线就会透成一条实线 —— 所以先用一条与边等宽的**不透明**渐变带铺底。
   案例垫纯白（它格子本来就白）；本表三档底色（`#0a0a0a` 只读 / `#1a1a1a` 可编辑 / `#171717` 表头与行号列），
   垫底取该格底色 `--cell-under`：写死表格底色会在可编辑列露一条更暗的 2px 槽。
   ⚠️ `background-origin` 必须是 `border-box`（默认 `padding-box` 会让垫底落进格内、白垫一层）。
4. **只给外圈挂类，"内部无线"是结构上必然。**
   选区与复制区都只把边类挂在**外圈**那排格子上，内部格一个类都不挂。
   代价（**已知且接受**）：紧贴时邻居的实线会压住虚线约 **1px** —— 只接受 1px，2px 就是 bug（见第 1 条）。

## 三、完整可运行代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>选择 / 复制区边框最小案例（本仓库实现）</title>
<style>
  :root { --bg:#0a0a0a; --grid:#2a2a2a; --line:#007a55; --edge-w:3px; --copy-w:2px; }  /* --copy-w = --edge-w − 1 */
  body { margin:24px; background:#0a0a0a; color:#e5e5e5;
         font:13px/1.4 ui-sans-serif, system-ui, "Microsoft YaHei", sans-serif; }
  .hint { color:#8a8a8a; margin:14px 0 0; }
  table { border-collapse:separate; border-spacing:0; user-select:none; }

  /* 格线在**格子自己**身上（本表是 border-r/border-b，不是 border-spacing 的背景缝） */
  td { position:relative; width:64px; height:24px; text-align:center; background:var(--bg);
       border-right:1px solid var(--grid); border-bottom:1px solid var(--grid); }
  td.editable { background:#1a1a1a; --under:#1a1a1a; }      /* 底色变了，垫底跟着变 */
  td.cell-selected { box-shadow: inset 0 0 0 9999px rgb(0 122 85 / 0.08); }

  /* ---- 选区实线：一个类管一条边（变量），默认 0 --------------------------------------------- */
  .cell-selectable { --edge-top:0px; --edge-right:0px; --edge-bottom:0px; --edge-left:0px; }
  .cell-selectable::before {
    content:""; position:absolute;
    inset:-2px;                       /* 向外 2px = 线宽 − 1 → 格外 1 + 与格线重合 1 + 格内 1 */
    border-style:solid; border-color:var(--line);
    border-width:var(--edge-top) var(--edge-right) var(--edge-bottom) var(--edge-left);
    pointer-events:none; z-index:1;   /* 格内层：实线在虚线之下 */
  }
  .cell-edge-top    { --edge-top:var(--edge-w); }
  .cell-edge-right  { --edge-right:var(--edge-w); }
  .cell-edge-bottom { --edge-bottom:var(--edge-w); }
  .cell-edge-left   { --edge-left:var(--edge-w); }

  /* ---- 复制区虚线：同样一条边一个变量，外加一层不透明垫底 ----------------------------------- */
  .cell-copy-top, .cell-copy-right, .cell-copy-bottom, .cell-copy-left {
    --copy-top:0px; --copy-right:0px; --copy-bottom:0px; --copy-left:0px;
    /* ‼️ 这里**不提整格 z-index**（见"四条不变量"第 1 条）。 */
  }
  .cell-copy-top    { --copy-top:var(--copy-w); }
  .cell-copy-right  { --copy-right:var(--copy-w); }
  .cell-copy-bottom { --copy-bottom:var(--copy-w); }
  .cell-copy-left   { --copy-left:var(--copy-w); }
  .cell-copy-top::after, .cell-copy-right::after, .cell-copy-bottom::after, .cell-copy-left::after {
    content:""; position:absolute;
    inset:-1px;                       /* 与格线重合 1px + 格内 1px = 实线**靠内那 2px** */
    border-style:dashed; border-color:var(--line);
    border-width:var(--copy-top) var(--copy-right) var(--copy-bottom) var(--copy-left);
    pointer-events:none; z-index:2;   /* 格内层：虚线压住实线 —— 只靠这一条 */
    background-image:
      linear-gradient(var(--under,var(--bg)),var(--under,var(--bg))),
      linear-gradient(var(--under,var(--bg)),var(--under,var(--bg))),
      linear-gradient(var(--under,var(--bg)),var(--under,var(--bg))),
      linear-gradient(var(--under,var(--bg)),var(--under,var(--bg)));
    background-repeat:no-repeat;
    background-size:100% var(--copy-top), var(--copy-right) 100%, 100% var(--copy-bottom), var(--copy-left) 100%;
    background-position:top left, top right, bottom left, bottom left;
    background-origin:border-box;     /* 默认 padding-box 会让垫底落进格内、白垫一层 */
  }
</style>
</head>
<body>

<table><tbody id="t"></tbody></table>
<p class="hint">拖拽 = 选区（实线 3px）；<b>Ctrl+C</b> = 复制区（虚线 2px，虚线取实线靠内那 2px）。</p>

<script>
const COLS = 7, ROWS = 6
const tbody = document.getElementById("t")
const 可编辑列 = new Set([1, 3])                       // 模拟本表的"可编辑列"（底色 #1a1a1a）
for (let r = 0; r < ROWS; r++) {
  const tr = document.createElement("tr")
  for (let c = 0; c < COLS; c++) {
    const td = document.createElement("td")
    td.className = "cell-selectable" + (可编辑列.has(c) ? " editable" : "")
    td.dataset.base = td.className
    td.textContent = 可编辑列.has(c) ? "5" : "0"
    tr.appendChild(td)
  }
  tbody.appendChild(tr)
}
const tds = [...tbody.querySelectorAll("td")]
const cell = (r, c) => tds[r * COLS + c]
const 框 = (a, b) => ({r1: Math.min(a.r, b.r), r2: Math.max(a.r, b.r), c1: Math.min(a.c, b.c), c2: Math.max(a.c, b.c)})
const 边类 = (r, c, B, pre) => {
  const out = []
  if (r === B.r1) out.push(`${pre}-top`)
  if (r === B.r2) out.push(`${pre}-bottom`)
  if (c === B.c1) out.push(`${pre}-left`)
  if (c === B.c2) out.push(`${pre}-right`)
  return out
}
let 锚点 = null, 选区 = null, 复制区 = null

/** 每次重画都从 data-base 重建类名：选区/复制区**只给外圈**挂类 → "内部没有线"是结构上必然的 */
function 重画() {
  tds.forEach((td) => (td.className = td.dataset.base))
  const 上类 = (B, sel, pre) => {
    for (let r = B.r1; r <= B.r2; r++) for (let c = B.c1; c <= B.c2; c++) {
      const td = cell(r, c)
      td.className = [td.className, sel, ...边类(r, c, B, pre)].filter(Boolean).join(" ")
    }
  }
  if (选区) 上类(选区, "cell-selected", "cell-edge")
  if (复制区) 上类(复制区, "", "cell-copy")      // 复制区只挂边类，没有额外底色
}

tbody.addEventListener("mousedown", (e) => {
  const td = e.target.closest("td"); if (!td) return
  const i = tds.indexOf(td); 锚点 = {r: (i / COLS) | 0, c: i % COLS}
  选区 = {r1: 锚点.r, r2: 锚点.r, c1: 锚点.c, c2: 锚点.c}; 重画()
})
tbody.addEventListener("mouseover", (e) => {
  if (!锚点) return
  const td = e.target.closest("td"); if (!td) return
  const i = tds.indexOf(td); 选区 = 框(锚点, {r: (i / COLS) | 0, c: i % COLS}); 重画()
})
window.addEventListener("mouseup", () => (锚点 = null))
window.addEventListener("keydown", (e) => {
  if ((e.ctrlKey || e.metaKey) && e.key.toLowerCase() === "c") {
    e.preventDefault()
    复制区 = 复制区 && JSON.stringify(复制区) === JSON.stringify(选区) ? null : (选区 ? {...选区} : null)
    重画()
  }
})
</script>
</body>
</html>
```

## 四、落进本表还要接上的东西（最小案例里省掉了）

- **层高阶梯**：最小案例没有冻结列/吸顶表头，所以只有格内那两层（1 / 2）。本表另有
  `--z-focus (30) < --z-edge (41) < --z-pinned (50) < --z-pinned-edge (51) < 吸顶表头 (60)`；
  而且**冻结列的邻格也在冻结层**，实线"格外那 1px"会被它盖掉 → 冻结区的边界格才需要再提一级
  （这类"整格提层"只在**冻结列**上成立，复制区一律不许用，见不变量 1）。
- **边是怎么算出来的**：本表用 TanStack Table v9 的 `cell.getSelectionEdges()`（每格四条边）
  与 `copyRingEdge()`（按复制源的 id 集合算外圈），见 `components/actions-table/classes.ts`。
- **memo**：边类必须在**行那层**算好再传下去，别让格子自己去读库的选区状态 —— 否则 memo 看不见变化、轮廓留在旧位置。

## 五、与原案例的差异（照抄会踩的四处）

| 原案例 | 本表 | 为什么 |
| --- | --- | --- |
| 整格 `z-index: 10` 让虚线永远在最上 | **不提整格层**，只靠格内 `::before`(1) < `::after`(2) | 提层会咬掉邻格选区边框 **2px**（差分实测 96 个绿像素；不提层为 0，效果逐像素不变） |
| `border-spacing: 1px` 的背景缝当格线 | 格线是格子自己的 `border-right / border-bottom` | 本表没有 spacing；两种网格模型下"格外 1px"的算法不同 |
| 实线用 `outline: 3px` + `outline-offset: -1px` | `::before` + `inset: -2px` + 逐边 `border-*-width` | `outline` 四边同宽、按 border box 算，做不出"一个类管一条边"（内部会被整圈上色） |
| 垫底 `2px solid #fff` | `--cell-under`（该格自己的底色） | 本表三档底色；写死会在可编辑列露一条更暗的 2px 槽 |
