# FSM → mot

只有 **三条证据齐全** 的才写成 `fsm → mot`：

1. exe 里该动作、分支确实加载这个 FSM；
2. 该角色的 `saveMotId*_`、`通用 mot` 包含这个 mot；
3. 该 mot 的 flags 有 `Flag1 & 16`。

只列有 `plXXXX_action.msg` 的玩家目录；`pl0001` / `pl0101` / `pl8000` 没有动作表，已排除。
